## Synthesis and overlap risks

1. **Temporal + layerwise detection is already present in ANODYNE.** Combining these ingredients alone cannot support a novelty claim.
2. **Layer-criticality defenses are established.** FedSurrogate and the LSA seed paper use layer criticality. A detector that simply emphasizes “important layers” overlaps and could be evaded adaptively.
3. **The candidate study axis is explicit relational cross-layer behavior plus a matched LSA evaluation.** The inspected sources do not establish that this exact component combination is novel. This is an empirical question, not a novelty claim.
4. **Scientifically justified positioning:** treat TCLAD-FL as a comparative evaluation protocol. Test whether cross-layer relationships add out-of-sample signal beyond layerwise-temporal features and whole-update baselines. If they do not, report the null/negative result and position the outcome as LSA benchmarking/ablation.
5. **Reproduction boundary:** the seed paper specifies layer substitution, iterative BC-layer selection, fine-tuning, and a smoothed layer-mask equation, but official code was not found in the reviewed sources. Our current output-layer mask approximation omits the substitution search and cannot be called exact LSA.

## Search scope limitations

This review is not systematic. Follow-up candidates include FLAME, FoolsGold, MultiMetrics, SnowBall, RLR, Multi-Krum, coordinate median/trimmed mean, layer-wise poisoning attacks, and other recent defenses. “Not verified” means not found in inspected primary sources, not proof of absence. Verify venue metadata and code before submission.
